The Internet Public Library has no user accounts. Reading is free and open, with no sign-up, and contributions happen on GitHub.

How to take part without an account

  • Suggest a resource — opens a prefilled issue on GitHub.
  • Report a problem — broken links, outdated or wrong information.
  • Edit pages on GitHub — every page has an "Edit" tab that opens its source file.
  • Contribution guide — what we accept and how review works.

A GitHub account is only needed to contribute. IPL does not store passwords or personal data.
