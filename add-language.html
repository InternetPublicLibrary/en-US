Add Your Language

Help us make education accessible to everyone by translating IPL into your language.

Getting Started

  1. 1
    Join our community
    Introduce yourself in our GitHub Discussions
  2. 2
    Fork the repository
    Create a fork of the IPL website repository
  3. 3
    Create language folder
    Create a folder with your language code (e.g., es-ES, fr-FR)
  4. 4
    Translate content
    Start translating pages from English
  5. 5
    Submit a pull request
    We'll review and merge your translations
