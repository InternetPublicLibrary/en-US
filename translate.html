How to Contribute Translations

1

Fork the Repository

Start by forking our GitHub repository to your account.

2

Create a Language Folder

Create a new folder with your language code (e.g., es-ES for Spanish).

3

Translate Content

Copy the English content and translate it, keeping the same file structure.

4

Submit a Pull Request

Submit your translations for review. Our team will help you with any issues.

Translation Guidelines

  • Use natural, native-sounding language
  • Keep technical terms consistent throughout
  • Don't translate code examples or URLs
  • Ask questions in GitHub discussions if unsure
